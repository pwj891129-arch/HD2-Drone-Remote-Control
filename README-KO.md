# HD2 드론 원격조종

**헬다이버즈 2용 0.2.33 실험 버전입니다. 기본적으로 솔로 플레이에서 작동합니다.**

[English guide](README.md) | [0.2.33 다운로드](https://github.com/pwj891129-arch/HD2-Drone-Remote-Control/releases/tag/drone-remote-control-0.2.33-test)

## Nexus Mods 페이지 안내

업데이트 업로드 중 실수로 Nexus Mods 모드 페이지를 삭제하여 복구를 요청했습니다.
복구가 어려우면 새 페이지에 다시 업로드하겠습니다. 복구 전까지 버전과 업데이트는
GitHub에서 제공합니다. 이용에 불편을 드려 죄송하며 기다려 주셔서 감사합니다.

## 주요 기능

3인칭 카메라, 키보드 이동, 마우스 조준과 수동 공격으로 드론을 직접 조종합니다.

- 가드 독, 로버, 핫 독, K-9, 도그 브레스 배낭 지원.
- G-50 씨커와 G-60 대전차 씨커 지원.
- 고정 단축키가 아닌 게임에서 설정한 키보드·마우스 입력 사용.
- 관성이 적용된 이동과 근사 방식의 표면 회피.
- 거리, 탄약, 열 정보 표시.
- K-9 다음 사격 준비율과 남은 대기 시간 표시.
- 자동 조준, 씨커 유도 보조, 멀티플레이 허용을 각각 설정 가능. 기본값은 모두 **OFF**.
- 하나의 ZIP에 모든 옵션 메뉴 번역 포함.

## 요구 사항

- **Arsenal**: 모드 가져오기와 배포에 필요합니다.
- **Bingus Shared Loader / API 1**: 필수이며 이 모드에 포함되어 있지 않습니다.
- **Bingus's Mod Options Menu / API 1, 버전 3 이상**: 인게임 옵션을 바꾸려면 필요합니다.
  설치하지 않으면 자동 조준, 씨커 유도 보조, 멀티플레이 허용은 OFF로 유지됩니다.

## 설치

1. 헬다이버즈 2를 완전히 종료합니다.
2. [최신 릴리스](https://github.com/pwj891129-arch/HD2-Drone-Remote-Control/releases/tag/drone-remote-control-0.2.33-test)에서
   **Drone-Remote-Control-0.2.33-private-test.zip**을 다운로드합니다.
3. 다국어 ZIP을 Arsenal로 가져와 이전 버전을 교체합니다.
4. **Backpack and Seeker Control**을 활성화하고 Bingus Shared Loader로 배포한 뒤
   게임을 다시 실행합니다.

여러 버전을 동시에 활성화하지 마세요. 선택적으로 제공되는 `.sha256` 파일은
다운로드 파일의 무결성을 확인하는 체크섬이며, 가져올 모드 파일이 아닙니다.

## 조작 방법

**아래 이름은 게임 설정의 기능 이름입니다. 각 기능에 지정한 키나 마우스 버튼을
사용하며 특정 키 문자로 고정하지 않습니다.**

### 가드 독 배낭

**드론이 배낭에 완전히 도킹된 상태에서 원격조종을 시작하세요.**

1. 임무에서 지원하는 배낭을 착용합니다.
2. 드론이 공중에 있으면 **배낭 기능**으로 회수하고 완전히 등에 붙을 때까지 기다립니다.
3. **조준 모드 전환**을 누른 채 **배낭 기능**을 누른 다음 두 입력을 모두 놓습니다.
4. 전개 준비와 카메라 전환이 끝날 때까지 기다립니다.
5. 조종 중 **배낭 기능**을 다시 누르면 종료됩니다.

배낭 드론의 조종 거리는 플레이어 기준 **100m**입니다. 경계에서 바깥쪽 이동만
제한하며 안쪽·옆쪽 이동은 가능합니다. 외부 움직임으로 경계를 넘으면 **5초** 동안
돌아올 수 있고, 돌아오지 못하면 조종이 종료됩니다. 탄 소진이나 완전 과열이
확인되면 기본 AI 조종으로 복귀합니다. 모드가 탄약을 보충하지는 않습니다.

### 씨커 드론

**조준 모드 전환**을 누른 채 **빠른 투척**으로 던진 다음 두 입력을 모두 놓습니다.
전개 상태가 **0.5초** 동안 안정적으로 유지되면 조종이 시작됩니다.

다음 방법도 사용할 수 있습니다.

1. **투척무기 들기**로 씨커를 손에 듭니다.
2. **조준 모드 전환**을 누른 채 **공격**을 눌렀다가 놓아 던집니다.
3. **조준 모드 전환**도 놓고 조종 시작을 기다립니다.

조종 중 **공격**을 새로 누르면 폭파를 요청합니다. **조준 모드 전환은 폭파나
조종 종료에 사용하지 않습니다.**

씨커는 거리 제한과 복귀 기능이 없으며 전개 후 **30초** 동안 유지됩니다.
폭발 후 마지막 시점을 **0.7초** 유지한 뒤 플레이어 시점으로 돌아옵니다.

### 이동과 공격

- **전진·후진·좌측 이동·우측 이동**: 수평 비행.
- **회피**: 상승.
- **앉기**: 하강.
- **시점 조작**: 시야 회전과 조준.
- **공격**: 배낭 드론 무기 발사 또는 씨커 폭파.

## 인게임 옵션

Bingus's Mod Options Menu를 설치한 경우 인게임 모드 옵션에서 **드론 원격조종**을
선택합니다. 모드 제목도 게임의 텍스트 언어 설정을 따릅니다.

- **자동 조준**: 배낭 드론의 표적 추적. 기본 **OFF**.
- **씨커 유도 보조**: 적 추적 보조. 이동·마우스 입력이 우선합니다. 기본 **OFF**.
- **멀티플레이 허용**: 파티원이 있어도 자신의 드론을 조종하도록 허용합니다.
  배낭과 씨커에 모두 적용되며 기본 **OFF**입니다.

멀티플레이는 실제 게임 환경에서 검증되지 않은 실험 기능입니다.
활성화해도 방장·참가자의 정상 작동과 동기화를 보장하지 않습니다.

## 언어

**하나의 ZIP에 모든 옵션 메뉴 번역이 들어 있습니다.** 영문·한국어 버전을 따로
다운로드할 필요가 없습니다.

인게임 모드 제목, 옵션 이름과 설명은 게임의 **텍스트 언어** 설정을 자동으로 따릅니다.
지원하지 않는 언어나 누락된 번역은 영어로 표시합니다.

지원 언어: 영어, 프랑스어, 이탈리아어, 독일어, 스페인어, 라틴 아메리카 스페인어,
일본어, 한국어, 브라질 포르투갈어, 포르투갈어, 폴란드어, 러시아어, 중국어 간체,
중국어 번체.

인터넷 연결이나 별도 언어 팩은 필요하지 않습니다. Arsenal 항목은 영어로 유지되며,
드론 HUD 상태 문구는 옵션 메뉴 번역에 포함되지 않습니다.

## 문제 해결

- Shared Loader 설치, 모드 활성화·배포, 중복 버전 여부를 확인하고 교체 후에는
  게임을 완전히 다시 실행하세요.
- 배낭 드론은 완전히 도킹한 뒤 설정된 **조준 모드 전환 + 배낭 기능**을 사용하고
  두 입력을 모두 놓으세요.
- 파티원이 있으면 **멀티플레이 허용**을 켜야 합니다. 이 기능은 실험적입니다.
- 조종이 시작되지 않으면 `DroneRemoteControl.log`의 거부·종료 이유를 확인하세요.
  지원되는 키보드·마우스 입력이 필요하며 컨트롤러 지원은 보장하지 않습니다.
  표면 확인 실패 시 안전을 위해 비행이 일시 정지할 수 있습니다.

## 주의 사항

실험 버전이며 게임 업데이트로 호환성이 깨지거나 게임이 종료될 수 있습니다.

표면 회피는 정확한 외형 충돌이 아닌 근사 방식입니다. 복잡한 지형, 움직이는 적,
깊이 박힌 씨커에서는 예상치 못한 동작이 발생할 수 있습니다. 최신 수정은 실제
플레이 검증이 필요하며 모든 끼임 문제가 해결되었다고 확정하지 않습니다.

**멀티플레이는 기본 OFF이며 실제 플레이에서 검증되지 않았습니다.**
방장·참가자의 정상 작동과 동기화를 보장하지 않습니다.
게임이 포커스를 잃거나 안전 검사에 걸리면 조종이 종료되고 플레이어 시점·입력으로
돌아갈 수 있습니다.

안티치트 호환성과 계정 안전을 보장하지 않습니다. 사용에 따른 책임은 사용자에게 있습니다.
